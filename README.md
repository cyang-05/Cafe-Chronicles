Cafe Chronicles: A Java 


📖 About the Game
Cafe Chronicles is a Java text-based adventure game where you step into the role of a wandering barista on a quest to craft the perfect drink. Navigate through whimsical environments, solve clever riddles, and collect hidden ingredients to complete your recipe.


Key Features:
🎯 Riddle-based challenges

🌲 Explore unique settings like enchanted forests and quiet valleys

🧩 Puzzle-solving and item discovery

☕ A final drink to be crafted from gathered ingredients


🎮 How to Play
Run the game from your terminal or IDE.

Follow the text prompts to explore locations and interact with Berta, the cafe's manager.

Solve riddles to unlock hints.

Once all ingredients are found, return to your starting point to craft the drink and complete the game.


⚙️ Requirements
Java 8 or higher

🛠 Running the Game
Compile and run the game using the following commands:

- bash
- Copy
- Edit
- javac Cafe.java
- java Cafe
